# Flutter Popup Window Widget

Flexible popup/dialog widget with smooth animations.

## Features
- Custom content area
- Fade, slide, scale animations
- Dismissible overlay
- Configurable backdrop

## Usage
```dart
OnPopupWindow(
  child: Column(
    children: [
      Text("Content"),
    ],
  ),
)
```

## Installation
```yaml
dependencies:
  on_popup_window_widget: ^1.0.0
```
